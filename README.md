## 「偏離10個百分點」是什麼意思？

觀察正二占總資產的比例。收盤比例與目標相差至少10個百分點，就在下一個可交易日開盤調回目標。

| 目標正二比例 | 觸發買入 | 觸發賣出 |
|---|---:|---:|
| 50% | ≤40% | ≥60% |
| 60% | ≤50% | ≥70% |
| 80% | ≤70% | ≥90% |

例如本金100萬元，正二50萬元、現金50萬元。正二漲到75萬元時，總資產125萬元，正二占比為75÷125＝60%，與50%目標相差10個百分點，觸發賣出再平衡。執行時會納入當時開盤價與交易成本。

季度策略於新季度第一個可交易日開盤調回目標。0050股利於實際發放後的下一個可交易日才再投入；分割調整受益單位，不當作投資損益。

## 資料與方法

共有2,912個市場交易日；0050的22次配息與元大官方紀錄一致，證交所48筆行情抽查一致；缺價均為官方分割停牌。使用原始日價、官方分割與配息重建持倉。現金收益為固定利率情境，並非觀察到的歷史存款收益。

允許小數受益單位、固定滑價；未計個人稅負、券商最低費及T+2交割限制。一價日假設不成交，保留真實收盤估值；日線不能證明個別委託成交。這是當前歷史資料快照的模擬，未認證嚴格歷史版本或所有事件發布時刻。

14項測試與獨立重算通過。詳細資料品質與限制：[data_quality.json](data_quality.json)、[review.json](review.json)。

## 離線重現

Python 3.10+建議；僅使用標準函式庫，從已保存資料重跑不需網路或憑證。

```bash
python3 normalize.py
python3 -m unittest -v test_backtest.py
python3 backtest.py --input normalized.json --out results
python3 build_report.py
python3 validation/independent_backtest_review.py
```

- `raw/`：原始資料及官方公告。
- `results/`：各情境逐日資產、交易、設定與指標。
- `normalized.json`：已核對的行情及公司行動。
- `validation/`：獨立重算、敏感度與離線重跑證據。
- `START_HERE.txt`：詳細重現方式。

原研究覆核與檔案雜湊保留在`review.json`；後續呈現調整見`validation/presentation_updates.json`。
